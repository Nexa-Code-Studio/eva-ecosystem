\section{Daftar Istilah Penting}
\begin{description}[leftmargin=1.6em, style=nextline]
  \item[Consent Gate] Mekanisme persetujuan eksplisit di EVA Mobile yang memberi pengguna kendali penuh untuk mengizinkan atau menolak pembagian ringkasan data skrining/diari kepada psikolog sebelum sesi konsultasi.
  \item[DASS-21 (\textit{Depression, Anxiety, and Stress Scale})] Instrumen kuesioner psikologis terstandar berisi 21 butir pernyataan untuk mengukur tingkat gejala depresi, kecemasan, dan stres secara mandiri.
  \item[E2EE (\textit{End-to-End Encryption})] Skema enkripsi ujung-ke-ujung yang memastikan data cadangan dienkripsi pada perangkat pengguna sebelum dikirim ke penyimpanan awan.
  \item[EVA Coin] Satuan kredit virtual di dalam EVA Ecosystem yang dibeli pengguna melalui paket koin/QRIS untuk memesan sesi telekonseling dengan psikolog.
  \item[H+1 SOAP] Kebijakan batas waktu penyelesaian catatan klinis (\textit{Subjective, Objective, Assessment, Plan}) oleh psikolog maksimal satu hari setelah sesi video berakhir sebelum pelepasan honorarium.
  \item[LUNA AI] Asisten pendampingan kesehatan mental berbasis kecerdasan buatan pada EVA Mobile untuk percakapan reflektif suara dan teks.
  \item[Rekonsiliasi Keuangan] Proses pencocokan catatan transaksi koin, QRIS \textit{top-up}, pengembalian dana (\textit{refund}), dan pencairan honorarium psikolog (\textit{payout}) antara sistem internal EVA dan penyedia pembayaran di Web Admin.
  \item[SafetyNet] Protokol respons cepat krisis yang menyediakan tautan bantuan darurat resmi apabila terdeteksi indikasi risiko tinggi pada pengguna.
  \item[STR \& SIPP] \textit{Surat Tanda Registrasi} dan \textit{Surat Izin Praktik Psikologi}; dokumen legalitas wajib yang diverifikasi Web Admin sebelum psikolog diizinkan berpraktik di EVA Counselor.
\end{description}

Apabila Administrator, Psikolog Mitra, maupun Pengguna menemukan kendala teknis atau membutuhkan klarifikasi terkait kebijakan operasional yang belum tercakup di dalam buku panduan ini, silakan menghubungi kanal dukungan resmi berikut:
\begin{itemize}[leftmargin=1.4em]
  \item \textbf{Formulir Umpan Balik Publik}: Akses rute \texttt{/feedback} (Booth Feedback) pada Web Portal EVA Ecosystem.
  \item \textbf{Tim Pengembang \& Operasional}: Nexa Code Studio — Divisi Operasional EVA Ecosystem.
\end{itemize}
